01
Azure App Registration
Go to portal.azure.com → Azure Active Directory → App Registrations → New Registration.

Set redirect URI to:
https://your-app.vercel.app/api/oauth/callback

Under Certificates & Secrets, create a client secret.

Copy Client ID, Client Secret, and Tenant ID into your .env.
Pending
02
OneDrive OAuth
With AZURE_CLIENT_ID, AZURE_CLIENT_SECRET, and ONEDRIVE_REDIRECT_URI set in your environment, click Connect OneDrive below.

After authorizing, copy the access and refresh tokens from the callback page into your Vercel environment variables.
Pending
03
AWS S3 + IAM
In AWS Console → S3, create a bucket (e.g. my-gaming-clips).

Under Permissions, add this CORS config to allow video playback:

[{"AllowedOrigins":["*"],"AllowedMethods":["GET"],"AllowedHeaders":["*"]}]

In IAM, create a user with AmazonS3FullAccess (or a scoped policy), generate access keys, and set AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY in your env.
Pending
04
Activate Webhook
After OneDrive is connected and your app is deployed, click Setup Webhook to subscribe to changes in your Videos/Xbox Game DVR folder.

New clips saved by your Xbox will automatically be downloaded and uploaded to S3. Subscription expires every 24h — you'll need to renew it.
